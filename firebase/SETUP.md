# T1 한국판 아카이브 운영

기존 Firebase 프로젝트 riftbound-whale-28edd의 설정과 인증을 재사용합니다. 익명 인증, 서울 리전 Storage 버킷, Firestore 및 Storage 규칙을 연결했습니다.

제보는 검토 없이 즉시 공개됩니다. status의 approved 값은 공개 상태를 나타내는 내부 호환 필드이며 수동 승인을 의미하지 않습니다.

문서 ID는 KR-{선수}-{번호}입니다. 예: KR-Faker-2025. Firestore 규칙은 이 ID와 입력값의 일치를 검증하고 생성만 허용합니다. 동시에 여러 명이 같은 번호를 제출해도 첫 등록만 성공하며 일반 사용자는 덮어쓸 수 없습니다.

사진은 t1Evidence/{uid}/{문서ID}/{0,1,2}.jpg에 저장됩니다. 등록 전에는 제보자만 읽을 수 있고 문서가 공개되면 누구나 읽을 수 있습니다. 중복 제출로 사용되지 않은 사진은 해당 제보자가 정리할 수 있습니다. 브라우저는 /api/t1-image를 통해 공개 이미지를 조회합니다. 서버는 인증 없이 Firebase에 요청하므로 Storage 규칙을 우회하지 않습니다.

잘못된 제보를 숨길 때는 Firebase 콘솔에서 해당 문서의 status를 rejected로 바꾸세요. 번호를 재등록 가능하게 하려면 관리자가 해당 문서를 제거해야 합니다. admin 커스텀 클레임이 있는 계정만 클라이언트 수정/삭제가 허용됩니다.

firestore.rules에는 기존 collections/{userId} 규칙을 보존했습니다. Firebase 콘솔에 다른 기능의 규칙이 추가되면 변경사항을 병합하세요. storage.rules는 T1 사진만 허용합니다. 미확인 번호는 실제 미개봉을 보장하지 않습니다.
